## Plan and seams

Approved seam: `FCombatBattle` Start / Submit / Snapshot, with legal-move and legal-target queries and one bounded enemy-turn operation. Tests use public encounter definitions and deterministic seeds. Reflected value state retains IDs, initiative, budgets, turn and random progression; presentation references never enter the state. Four roles have basic attacks here; role abilities, rescue/death, expedition routing and save adapters are later tickets.

Use cardinal movement and Manhattan attack range on an 8x8 arena, occupied cells blocking travel, blocked-cell line of sight, one attack per turn, movement before/after attacking. These are labeled tactical adaptations. Initiative is d20 + modifier with stable ID tie-break. Natural 1 misses, natural 20 hits and doubles damage dice. Enemy planning is finite breadth-first search followed by commands through the same validation.

## Public interface for the next slice

`Combat/CombatBattle.h` is the authoritative seam. `FCombatEncounter` supplies board/blocked cells and combatant definitions. `FCombatBattle::Start` validates and seeds initiative atomically. `Submit(FCombatCommand)` returns accepted/rejected `FCombatResult` with roll/damage/feedback; rejection preserves snapshot and RNG. `LegalMoves`, `LegalTargets`, `Find`, `ActiveId` and read-only `Snapshot` support adapters. `PlayEnemyTurn` plans and submits at most three legal commands. `FCombatSnapshot` contains reflected value state (encounter, stable IDs, HP, RNG state, turn order/index, round, movement/action budgets and outcome), with no Actor/UObject references. Save/restore and run-level composition adapters remain later scope.

`AExpeditionBattleView` owns one battle and mirrors its snapshot into runtime meshes/camera. Controller selection and keyboard cursor are presentation state; mouse and keyboard dispatch the same cell action and combat commands. HUD reads legal queries and results. Later roles/rescue work should extend authoritative values and commands/tests here, not infer rules from transforms, HUD strings, or controller fields. One runtime build module remains.
