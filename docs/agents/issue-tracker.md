# Issue tracker: GitHub

The game repository is `AustinKelsay/expedition-rpg`; its GitHub Issues hold specs and dependency-ordered tickets. Use authenticated `gh` commands, explicit `--repo AustinKelsay/expedition-rpg`, and `--body-file` for multiline content. Read full issue bodies/comments before working. Approved tickets use `ready-for-agent`. Keep the parent spec open; record implementation evidence and resolve child tickets only after checks and review.

Use GitHub native sub-issues and blocked-by relationships where available, with readable Parent/Blocked by references in each ticket as durable fallback. PRs as a request surface: no.
