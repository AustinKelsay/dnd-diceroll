# Asset provenance

Before importing or replacing assets, follow [asset intake](agents/asset-intake.md) for candidate validation and handoff. Record each asset's provenance here.

The sandbox uses Unreal Engine's bundled basic cube. No external content has been imported.

For each imported asset or generated source, record its destination, author/provider, source URL or generation recipe, license, and modifications here. Keep editable source assets in `Art/` when introduced and import the runtime form into `Content/`.

For generation, editable source preparation or revisions, follow [asset production](agents/asset-production.md). Keep the [versioned asset record](agents/asset-manifests.md) with retained source files so agents can validate changes and plan updates to stable Unreal destinations.
