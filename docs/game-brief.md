# Game brief

The confirmed scope is a game-neutral workspace for building games with agents and Unreal Engine. The starter map is a development fixture: floor, lighting, and player start. It establishes no gameplay requirements.

These decisions are **undecided** and require design input before gameplay implementation:

- Core interaction, player goal, rules, and progression.
- Camera, input devices, accessibility, and interface.
- Art direction, audio, asset budget, and licensing constraints.
- Target platforms and minimum hardware.
- Single-player or multiplayer, persistence, and online services.

For the first playable slice, record the player action, observable result, failure conditions, and scope exclusions. Choose concrete acceptance criteria, an automation or manual check for each, and any asset dependencies. Keep new gameplay systems tied to those criteria.
