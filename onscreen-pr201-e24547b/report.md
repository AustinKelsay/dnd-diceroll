## 2. On-screen pass (1920x1080 plus a 1280x720 check)

Method: the #198/#197 rig (`rig/`): nested compositor, `wtype` for keys, `ptr2` virtual pointer, `grim -g <crop> -t ppm` **lossless** bursts (about 16 ms per crop, 160-260 frames per action) fired inside the burst so every frame of cast, release, flight and landing is on disk; luma by `tools/lumaburst.py` (same definition as `tools/impact_flash.py`: Rec. 709 weights on 8-bit sRGB, white = all channels >= 250). Boxes are hand placed around the caster (about 110x130 px, `csv/` file names say which burst; the box for `S1-*` bursts is the caster's cell). Fixtures: the PR's `cast3-*` (written by `test --filter Project.Tools.CaptureFixtures` in this checkout) edited by `rig/fx.py` only to move the units (see `fixtures-edit/`): **F1** = `cast3-default-seed-battle` (Vigil kit, the casters moved to range 3-4 of the raider and archer, party acts first), **F2** = `cast3-board-vault` (the finale; casters moved up to range, full HP), **F4** = `cast3-board-root-r002` (Root; the warlock Downed beside the druid). Input detail: arrow-key cursor tracking in `play.py` did not work for this build (the first attempts moved nothing), so `drv.py prep` drives the cursor to the cell by pressing the arrows to the board corner and back.

## Anomalies and process notes
- One SDL startup race (S4's first launch): relaunched.
- Two failed Resume relaunch attempts caused by `grim` "failed to create buffer" while Unreal loaded (free RAM was 393 MiB, 13.5 GB used of 15.7 GB with the game running); fixed by capturing a cropped region (as in #198's note) after the game was up.
- Cursor driving: the first arrow key after a mode key must reveal the cursor and the cursor-tracking helper from the #197 rig did not move it here, so `drv.py` runs the cursor to a corner and back. Several early attempts pressed nothing; those bursts were deleted and redone (and are not counted).
- The Vault fixture's wizard has no Magic Missile slot (`Kit 0/2 + Slot 0/2` on that fixture), so Magic Missile was run from the Vigil fixture (F1), where it cast.
- The default party's 2499 ms single frame (perf section).
- Not covered: ranger arrow, cleric tint comparison, Brace, duplicates, builder, static fallback, hit/spell flash on all three rigs, skip/2x/instant, the antlered raider foe next to the druid.
