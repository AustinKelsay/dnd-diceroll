Project-owned assets live under `/Game/DnDDiceRoll`.

Use `Maps`, `Blueprints`, `Materials`, `Meshes`, `Textures`, `Audio`, `UI`, and `Data` as those assets are introduced. Prefix levels `L_`, Blueprints `BP_`, materials `M_`, material instances `MI_`, static meshes `SM_`, textures `T_`, widgets `WBP_`, and data assets `DA_`.

`Maps/L_AgentSandbox` is the initial disposable development map. Keep experiments separate from production maps. Import third-party packs into their own top-level folder and record their source and license in `docs/assets.md`.
