## 5. Anomalies
- **SDL SIGFPE on launch**, once in 10 launches of the package: run C's first launch at 01:23:29Z (`logs/game-C-first-launch-sigfpe.log`, `handle_wl_output_done` in `SDL_waylandvideo.c:1016`); the relaunch worked. The known headless-output quirk, as in #196 and #197. The perf passes had none.
- **Nested compositor shows host monitors:** `hyprctl -i <my signature> monitors` on the new nested Hyprland listed two 0x0 phantom monitors (HDMI-A-1 and DP-2, with the host monitors' mode lists) next to my `HEADLESS-1`. They belong to my own instance (the instance's pid and `hyprland.lock` match my `Hyprland` process, and I only ever used `-i <my signature>`), the game opened on `HEADLESS-1` after `focusmonitor`, and I issued no command against any other instance. Same setup as the previous passes.
- **Pointer hover** did not raise a party-card panel in my rig (see 2b), so card details were shown through the number keys.
- **Pan:** keyboard Shift+WASD panning did nothing through `wtype` (Shift_L press, `-M shift`); middle-drag with the virtual pointer did pan, so the pan-stop pose was reached with drags (up for toward the camera, left for right), twice in a row.
- **Lock:** the single on-screen session held the machine lock 01:18:59Z-01:33:38Z (14.7 min, under the 30-minute guidance). The package job waited no time; the perf warm-up waited about 1.5 minutes (01:12 to 01:13:24Z) while another worker's package job held the lock.
- No crash report, no `Error:`, no ensure in any log; no `Saved/Crashes` in the package.
